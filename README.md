# 德语语音综合练习 · 点词发音

一个单文件的德语发音练习页：点任意单词即发声，手机上也能用。

在线访问：**https://enzo-river.github.io/deutsch-phonetik/**

## 内容

| 模块 | 内容 | 数量 |
|---|---|---|
| 一 | 元音长短音对比（a / e / i / o / u / ö / ä） | 12 组 · 24 词 |
| 二 | 复合元音与变元音（au、ei·ai·ey·ay、eu·äu，ä / ö / ü 长短） | 6 组 · 15 词 |
| 三 | 辅音字母组合（ch[x] · ch[ç]、sch、sp、st、qu、pf、ng、-ig） | 9 条 · 20 词 |
| 附 | 朗读练习 | 8 词 |

## 用法

- 点任意单词 → 朗读该词，卡片同步高亮
- 点每行右侧 **▶** → 按「先长音、后短音」对比连读
- 顶部可切语速：慢 0.75 / 中 1.0 / 快 1.2（只改速度，不变调）
- 「停止」可随时打断；「测试」会朗读 *Haus* 并显示诊断信息

## 为什么发音一定可靠

页面**不调用** Web Speech API，也**不依赖**任何在线 TTS 服务。

57 个词的德语发音由 macOS 的系统德语语音 **Anna（de_DE）** 预先生成，转成 AAC（32 kbps 单声道 m4a）后以 base64 内嵌在 `index.html` 里，运行时通过 `<audio>` 播放。因此：

- 离线可用，断网也能读
- 不受对方设备是否安装德语语音影响，**发音必然是德语**
- 微信内置浏览器、Safari、Chrome 表现一致

播放链路做了三级回退：内嵌音频 → 系统德语语音 → 在线合成；内嵌音频路径还会在 `data:` 被 CSP 拦截时改用 Blob URL。

## 技术说明

- 单文件，无构建、无依赖、无后端
- 响应式布局，适配 375 px 起的手机屏幕与桌面
- 语速通过 `audio.playbackRate` 控制（浏览器默认保持音高）
- 首词在点击的同步调用栈内起播，规避移动端自动播放策略

## 体积说明

`index.html` 约 492 KB，其中约 465 KB 是 57 段内嵌音频。这是「离线可播 + 发音必定是德语」的代价。
